# VAMSilk

Учебный мессенджер: React-фронтенд и небольшой Go-бэкенд с SQLite.

## Запуск

Сначала запустите API в первом терминале:

```powershell
cd backend
go run .
```

Затем во втором терминале запустите React-приложение:

```powershell
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`, зарегистрируйте нового пользователя и войдите. Экран авторизации подключён к Go API через Vite-прокси.

Полное описание базы, маршрутов API и примеры запросов — в [backend/README.md](backend/README.md).

## Развёртывание

В проекте есть `Dockerfile`: он собирает React-интерфейс и Go API в один контейнер. Для хостинга укажите Dockerfile как способ сборки, порт `8080` и создайте постоянный диск, смонтированный в `/data`. Задайте переменную окружения `JWT_SECRET` со случайным длинным значением. Без постоянного диска SQLite-база будет очищаться при каждом перезапуске сервиса.
